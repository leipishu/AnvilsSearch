============================================================================
  Build Variants
============================================================================

  Tinker's Search provides two builds with identical features
  except for pinyin search support:

  Full Build
  ──────────
    - File name: tinkers-search-<version>.jar
    - Includes pinyin4j via Jar-in-Jar
    - Supports pinyin search (full pinyin and initials)
    - Approximate size: 420 KB

  Lite Build
  ──────────
    - File name: tinkers-search-<version>-lite.jar
    - Does NOT include pinyin4j
    - Pinyin search is disabled; literal text matching still works
    - Approximate size: 215 KB

  Both builds share all other features: fluid search, three tabs
  (Smeltery / Materials / Alloy), alloy query, favorites, fluid
  detail screen, JEI integration, bookmarks, refresh, and scrolling.
